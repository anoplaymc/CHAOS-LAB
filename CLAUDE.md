# CHAOS LAB

@AGENTS.md

The rule above about game mods is mandatory: read the ChaosScript instructions, study the API, look at working examples, write the logic in ChaosScript through the existing Mod API, check syntax and permissions, run the mod's tests, fix what they find, and confirm the mod loads. JavaScript and TypeScript are for the engine, editor, loader, API and tools, and never for a mod's game logic.

The user doesn't need to know ChaosScript. Turn a plain request into a mod by following [docs/MODDING_WORKFLOW.md](docs/MODDING_WORKFLOW.md). The `chaosscript-developer` skill covers the same process.
